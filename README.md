## Layout

The folder names come from the sync integration and are not hand-organised:

```
Data Structures & Algorithms/
  <problem-slug>/
    submission-0.py    ← first accepted submission
    submission-1.py    ← a later re-solve
```

More than one `submission-*.py` under a problem means I came back to it — usually to replace
a first pass that worked but was the wrong complexity.

## Why this is public

Interview prep is repetition, and repetition is easier to keep honest when it is visible.
There is nothing clever here; the engineering work worth reading is in
[queryguard](https://github.com/jliu4950/queryguard) and
